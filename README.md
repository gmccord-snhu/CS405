# CS405  
SNHU CS-405 Secure Coding Portfolio

## Overview
This repository contains selected work completed for CS-405: Secure Coding at Southern New Hampshire University. The portfolio demonstrates my understanding of secure coding practices, security policy development, vulnerability prevention, and professional communication in cybersecurity.

## Included Artifacts

### Project One – Security Policy
A written security policy covering core security principles, coding standards, authentication, authorization, auditing, encryption, and defense-in-depth practices.

### Project Two – Presentation
A presentation explaining secure development concepts, risk management, threat prioritization, and how security controls can be integrated into the software development lifecycle.

### Coding ZIP Files
Source code assignments and programming exercises completed during the course. These files demonstrate secure coding techniques such as input validation, exception handling, encryption, and safer programming practices.

### Portfolio Journal Reflection
A written reflection summarizing what I learned in CS-405, how my understanding of software security evolved, and how these lessons apply to professional software development.

## Skills Demonstrated
Through these artifacts, I demonstrated the ability to:

- Apply secure coding principles
- Reduce common software vulnerabilities
- Develop security policies and standards
- Use defensive programming techniques
- Communicate technical security concepts
- Connect cybersecurity practices to real-world software development
